# airtest 전용 - 반드시 --no-deps 로 설치할 것
#
#     pip install --no-deps -r requirements-airtest.txt
#
# [왜 분리했나]
# airtest 1.3.4 의 메타데이터는 opencv-contrib-python<=4.6.0.66 을 요구한다.
# 그런데 4.6.0.66 은 numpy 1.x ABI 로 빌드되어 numpy 2.x 환경에서 import 시 크래시하고,
# numpy 1.26.4 는 Python 3.14 용 휠이 존재하지 않는다.
# 즉 Python 3.14 에서는 airtest 의 선언된 제약을 그대로 만족시킬 방법이 없다.
#
# 그래서 opencv 4.14 를 쓰면서 airtest 의 상한만 무시한다.
# 이 상태로 requirements.txt 에 함께 넣으면 pip 리졸버가
# ResolutionImpossible 로 설치를 거부하므로 파일을 분리했다.
#
# airtest 의 실제 의존 패키지들은 requirements.txt 하단에 모두 명시되어 있으므로
# --no-deps 로 설치해도 누락되는 것은 없다.
#
# [주의] Python 3.11 을 쓸 수 있다면 airtest==1.4.3 + numpy==1.26.4 +
# opencv-contrib-python==4.6.0.66 조합이 정석이며 이 우회가 필요 없다.

airtest==1.3.4
